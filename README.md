# Ritvik Varma — Portfolio & Creative Experiments

An interactive, high-performance portfolio engineered with pure Vanilla JavaScript, modern CSS3, and responsive physics-driven interactions.

---

## 📁 Project Structure

```text
project-1/
├── assets/          # Compressed modern WebP media assets & original backups
├── content/         # Markdown content and articles
│   └── blogs/       # Blog posts rendered dynamically
├── css/             # Stylesheets & design tokens
│   └── style.css    # Core design system, layout, dark/light themes
├── js/              # Application scripts & interactive physics
│   └── script.js    # Data repositories, magnetic cursor, 3D tilt, Lenis
├── index.html       # Semantic HTML5 entry page (Optimized & Non-blocking)
└── README.md        # Documentation & project guide
```

---

## 🚀 Performance & Core Web Vitals Highlights

- **Optimized Image Delivery**: 90.5% payload reduction using modern `.webp` compression.
- **Zero Render-Blocking**: Non-blocking asynchronous font loading and deferred scripts.
- **CLS Prevention**: Explicit image dimension attributes and aspect-ratio reservation.
- **60fps Physics & Smooth Scrolling**: Lenis smooth scroll and passive event listeners.

---

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5 (WAI-ARIA accessible)
- **Styling**: Vanilla CSS3 (Custom properties, clamp typography, theme variables)
- **Interactions**: Vanilla JavaScript (ES6+, DOM state machine, RAF game loop)
- **Smooth Scroll**: Lenis Scroll Engine
